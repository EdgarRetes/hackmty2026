# Factoring Risk MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver an explainable, deterministic invoice-risk decision and term-sensitive investor recommendation, backed by official reference fields and demo fixtures for approval, review, and rejection.

**Architecture:** Add risk input fields and immutable assessment snapshots to Django, then implement a pure scorecard/pricing service consumed by dedicated API endpoints and the offer flow. Keep official values as dated, sourced snapshots and render the latest assessment in the existing Next.js offers page.

**Tech Stack:** Django 6.1, Django REST Framework, Python `Decimal`, Next.js 16, React 19, TypeScript, Tailwind CSS.

## Global Constraints

- Backend remains API-only and all responses under `/api/` are JSON.
- Environment-specific values remain outside shared settings.
- Frontend visible copy is Spanish; identifiers and types are English.
- The MVP uses deterministic synthetic companies and invoices shaped like official SAT, Banxico, INEGI and Basel data; it must not imply live validation.
- KYC/KYB onboarding, authenticated SAT download and production-regulated underwriting remain out of scope.
